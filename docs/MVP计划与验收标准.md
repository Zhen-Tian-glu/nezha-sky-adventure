# 《哪吒今天不闹海》第一版 MVP 计划与验收标准

版本：v0.9  
更新日期：2026-11-01  
状态：阶段 4 正式素材接入与动态表现增强已实现，模型及 Web 自测通过；用户美术/手感意见、微信工具与真机仍待验收。

## 1. 第一版只证明一件事

“连续点击让哪吒扑动起飞、不点击时受重力下落，并穿越随机上下障碍”是否直观、可控、公平、好玩，并让玩家愿意立即重试。

完整闭环：进入 → 待机 → 开始 → 随机场景 → 飞行避障 → 得分 → 碰撞失败 → 结算 → 重新开始。

第一版包含天宫、海底龙宫；每局开始随机选择一种，本局固定。天宫下方为山峰、石柱、火球，上方为乌云、雷电、风火轮，共 9 种组合；海底下方为山峰、石柱、水球，上方为海底妖怪，共 3 种组合。合计 8 种障碍类型、12 种场景内组合。

首版不包含广告、排行榜、角色养成、皮肤、道具、联网对战和长期运营。灰盒是第一版的前期验证过程，不单独替代完整第一版交付。

操作变更状态：操作方式于 2026-11-01 经用户确认后改为点击起飞，已实现版本 0.3.0。模型与 Web 自测通过，构建编号 tap-graybox-20261101-01；微信真机与用户手感仍待验收。

## 2. 核心飞行灰盒简报

- 验证问题：点击起飞、不点击下落是否容易理解，角色是否可控，失败原因是否清楚？
- 核心操作：每次点击触发一次向上动力，不点击自然下落，在通道间调整高度并连续穿越。
- 临时表现：色块、几何轮廓及简单反馈，优先完成输入、飞行、碰撞、死亡和重开。
- 首个时间盒：争取 90 分钟内得到可操作的飞行原型；这是检查点，不是完整阶段的交付承诺。
- 继续条件：新玩家看一次提示即可操作，试玩后主动愿意再玩。
- 调整条件：玩家理解规则，但控制高度困难、上下惯性不清晰或碰撞反馈不可信；先调整参数和判定。
- 暂缓扩充条件：多轮调整后仍难以控制或无法说明失败原因；先解决核心问题，再投入正式素材。

### 5. 游戏流程

- [ ] 首页显示待机角色及最高分，首次提示“点击起飞，连续点击保持飞行；不点击会下落”。

- [ ] 再玩一次清理上一局数据；返回首页正常；暂停时停止玩法更新，恢复需玩家确认。
