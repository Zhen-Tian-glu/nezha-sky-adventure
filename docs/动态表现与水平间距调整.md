# 0.6.2：增强动态表现与调整水平间距

日期：2026-11-01；构建：scene-motion-spacing-20261101-01。

## 本轮调整

根据用户反馈，增强实际可见的背景和障碍动态，并将“障碍物之间的距离”按前后两组的水平距离处理。用户指定的原哪吒、四组角色动作和上一版宽窄变化规则继续保留。

## 更明显的动态

| 内容 | 当前表现 |
| --- | --- |
| 天宫背景 | 中景云层移到上侧可见区域；中近景分别20/42 px/s漂移，增加风中光尘、柔和移动光束 |
| 龙宫背景 | 中近景分速移动，增加26个上升气泡、多层水流纹和透光 |
| 火球 | 图片宽度及火柱长度周期伸缩，配合火星和热流 |
| 水球 | 图片呼吸式伸缩、明亮水色变化，配合流纹和气泡 |
| 雷电 | 实际图片色调脉冲、内部多段雷光；主体不透明度始终不变 |
| 风火轮 | 轮链整体轻摆，内部轮辐光痕旋转 |
| 海底妖怪 | 身体轻摆、呼吸伸缩，配合鳞光、水纹和眼部变化 |

山峰、石柱和乌云的主体保持静态，只随场景水平移动；不把所有危险物都做成晃动目标。背景动态在待机及飞行时可见，首次起飞不会把背景时间重置；暂停、隐藏和结束时冻结，继续后从原时间恢复。受击的短反馈仍独立播放至结束。

## 画面与碰撞同步

新增 ObstaclePose，由渲染和物理共同使用相同的玩法时间、池槽位及类型配置。图片位置、尺寸改变时，alpha轮廓碰撞采用相同位置和尺寸，不留下“图片动了、碰撞没动”的隐藏危险区。

所有姿态都限制在原先预留的包络内：火球/水球及妖怪最多向远离通道的一侧回缩，风火轮轻摆时缩窄图像以预留左右活动空间；不会突然越过原本最窄通道。雷电只改变颜色，不让主体或碰撞凭空消失。上下净空仍按0.6.1规则，首组395～420，后期最窄240，相邻净空差至少40。

背景装饰不参与碰撞、不消耗玩法随机数，采用固定节点及单个环境Graphics。其时钟在待机按限幅帧时间推进，飞行按实际模拟时间推进，切换时不重复累计，不补算后台经过时间。

## 水平间距与节奏

此前中心间距主要为固定500～460，变化不明显。本版改为：

`实际间距 = max(当前档基准 + 随机[-20,20], 安全所需间距) + 随机[0,8]`

| 分数 | 目标基准中心间距 | 抽样平均实际间距 | 目标水平速度 |
| --- | --- | --- | --- |
| 0～4 | 480 | 约484 | 170 px/s |
| 5～11 | 455 | 约459 | 190 px/s |
| 12～21 | 430 | 约440 | 210 px/s |
| 22～34 | 415 | 约434 | 235 px/s |
| 35及以上 | 400 | 约433 | 255 px/s |

单位均为设计像素，表中距离指组中心到组中心，障碍后缘到下一组前缘的空白还需减去两组半宽。抽样覆盖50种子、每档超过3000个距离，不是每次开局的固定序列；完整最小/最大/平均值见 motion-062-spacing-stats.json。

安全间距仍按最大速度255、角色直径56、相邻中心落差和反应时间计算。高落差或宽障碍组合会自动多留空间，因此后期实际均值不会强行压到400。此设计让节奏逐渐紧凑，同时保留原可达性保证；已有组不会因为分数变化而瞬移。
