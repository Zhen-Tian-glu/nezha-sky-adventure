## 验收要求

小屏下可辨认；角色、武器及服装连续一致；独立帧留有透明边距，无邻帧污染；背景分层和滚动可用；危险轮廓与碰撞区域一致；正式素材来源与使用条件有记录。现有概念图和 GIF 的存在不能代替这些检查。

## 点击版素材调整要求

- 操作教学与手势改为连续点按，文案为“点击起飞，连续点击保持飞行；不点击会下落”。
- 起飞动作以每次点击触发的短扑动为单位，允许连点时顺畅重新触发；不能依赖持续长按循环。
- 起飞音效使用单次短音效，长按不循环触发。已有概念合图和 GIF 尚未按点击节奏验收。

操作方式于 2026-11-01 经用户确认后改为点击起飞，已实现版本 0.3.0。模型与 Web 自测通过，构建编号 tap-graybox-20261101-01；微信真机与用户手感仍待验收。

## 阶段 3 临时动画资源记录

当前动画来自 assets/scripts/gameplay/ObstacleMotion.ts 和 ObstacleMotionRenderer.ts，并非新增正式 PNG 或精灵序列。8 类图案中 5 类动态、3 类静态，运行时固定复用 4 个 InteriorMotion 节点。循环周期及危险范围见《动态障碍.md》。临时图形随代码版本 0.5.0 交付，不作为正式素材的尺寸、独立帧、来源或风格验收结果。

实际浏览器截图保存在项目 docs/verification/stage-3-<类型>-frame-a.png 与 frame-b.png（fireball / waterball / lightning / windwheel / seaMonster）；属于测试证据，不导入运行时 assets。
