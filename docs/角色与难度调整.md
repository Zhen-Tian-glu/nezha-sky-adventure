## 通道与难度

原版净空仅在基础值±20内变化，宽窄差不够明显。本版扩大范围，并要求相邻两组净空至少相差40设计像素，从有效区间直接随机抽取；既有窄通道，也有可调整节奏的宽通道。

| 分数 | 上下障碍包络间净空 | 目标水平速度 |
| --- | --- | --- |
| 0～4 | 340～420 px | 170 px/s |
| 5～11 | 310～390 px | 190 px/s |
| 12～21 | 285～365 px | 210 px/s |
| 22～34 | 260～340 px | 235 px/s |
| 35及以上 | 240～320 px | 255 px/s |

首组特别保留395～420的宽通道，给玩家起飞和适应的空间。速度沿用每秒最多增加12的平滑变化，上限保持255，避免同时大幅加速造成突兀难度。

净空变化在生成时决定，已进入屏幕的障碍不会突然收缩。相邻通道中心高度差最多45、边界安全距离90、角色半径28等约束保留；按最高速度检查离开上一组后到下一组的可用反应时间，不足时增加间距。最窄240净空仍通过原公共安全区及单次起飞可达性检查。图片透明轮廓比包络更宽容，实际可见通路可能稍大。
